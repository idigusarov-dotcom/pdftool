# PDF-помощник АкваТехСтрой

Программа для Windows для работы со сканами актов и расписок. Работает без интернета.
Исходные файлы она **никогда не изменяет**: результат всегда сохраняется в новый файл
(например, `расписки_с_подписями.pdf`).

## Как запустить (обычному пользователю)

1. Скачайте `PdfTool.exe`: GitHub → вкладка **Actions** → последняя успешная сборка → блок **Artifacts** → `PdfTool`.
   Если есть релиз, файл лежит и во вкладке **Releases**.
2. Распакуйте архив и запустите `PdfTool.exe` двойным щелчком.
   При первом запуске Windows может показать предупреждение «Windows защитила ваш компьютер».
   Нажмите «Подробнее» → «Выполнить в любом случае». Программа не подписана сертификатом, это нормально.
3. Первый запуск занимает 5–15 секунд: программа распаковывается.

## Что нового в версии 1.3 — новый интерфейс и подсказки
- **Меню слева** вместо вкладок: Подписи, Пакет, Сортировка, Картинка, Страницы и внизу «Справка».
  Вверху — название, версия, кнопки «Отменить/Повторить», переключатель тёмной темы, меню «ⓘ»
  (журнал ошибок, о программе) и **«?»**.
- **Каждый экран — три шага**: «1. Откройте → 2. Проверьте → 3. Сохраните». Сделанный шаг отмечается зелёной
  галочкой, следующий подсвечен — сразу видно, что делать дальше.
- **Файлы можно перетаскивать мышью** на плашки «Перетащите PDF сюда» или прямо в окно. По плашке можно и нажать —
  откроется обычный выбор файла.
- **Пошаговая подсказка**: кнопка «?» вверху или «Как пользоваться» на экране.
  - Экран затемняется, нужная кнопка подсвечивается, а рядом пояснение — что это и зачем нажимать.
  - Кнопки «Далее / Назад / Закрыть», работают и стрелки на клавиатуре, Esc, а также F1.
  - При первом открытии каждого экрана программа сама предложит показать подсказку (один раз).
  - Тот же текст целиком — на странице «Справка».
- **Уведомления вместо окон**: «Готово! …» появляется внизу справа и исчезает само.
  В уведомлении о сохранении есть кнопка «Открыть папку».
- Редкие настройки (шаблоны, зоны номера, цвет чернил, чувствительность) убраны в сворачиваемый блок
  **«Дополнительно»**.
- У всех кнопок есть всплывающие подсказки. Эмодзи заменены иконками — квадратиков вместо значков больше нет.
- Шрифт Inter встроен в программу (лицензия SIL OFL 1.1), иконки — Lucide (лицензия ISC). Файлы лицензий лежат
  в `app/ui/assets/`.
- Окно рассчитано на экраны 1366×768 и 1920×1080, учитывает масштаб Windows (125%, 150%). Если места мало,
  у экрана появляется прокрутка.

## Что нового в версии 1.2
- **Шаблоны бланков.** На экранах «Подписи» и «Сортировка», в блоке «Дополнительно», есть строка «Шаблон бланка».
  - Шаблон запоминает рамку подписи в акте, рамку в расписке, зоны номера квартиры, цвет чернил и чувствительность.
    Ещё он запоминает «отпечаток» бланка — расположение строк печатного текста на текущей странице.
  - Кнопки: «Сохранить», «Переименовать», «Удалить», «Экспорт…» (в файл .json для другого компьютера), «Импорт…».
  - Шаблоны лежат в `%APPDATA%\PdfTool\templates\`, по одному файлу на шаблон.
  - Галочка **«Определять бланк каждой страницы»**: если в одном файле бланки разного вида, программа сама подбирает
    для каждой страницы похожий шаблон и сдвигает зону номера вслед за бланком. Рамка подписи в акте тоже
    берётся из узнанного шаблона. Рамки, заданные вручную для отдельной страницы, не меняются.
    Узнанный бланк виден во всплывающей подсказке в столбцах «Кв.», а на экране «Сортировка» — в «Примечании».
  - Как сделать шаблоны для смешанного файла: откройте страницу с бланком первого вида, нарисуйте зоны и рамки,
    «Сохранить» → «Акт вид 1». Затем страницу второго вида → поправьте → «Сохранить» → «Акт вид 2».
- **Пакетный режим** — экран «Пакет»:
  - «Добавить пару…» — файл актов и файл расписок. Для каждой пары выбирается шаблон и имя результата
    (двойной щелчок по пути).
  - «Проверить во вкладке «Подписи»» открывает пару в обычной таблице. Исправьте сопоставление и рамки,
    вернитесь и нажмите «Взять сопоставление». Без этого страницы сопоставляются по порядку.
  - «Обработать все» работает в фоне, с полосой прогресса и кнопкой «Отмена». Отменённая пара файл не создаёт.
  - В конце — итог по каждой паре: сколько подписей поставлено, какие расписки без подписи (нет чернил в рамке),
    ошибки. Кнопка «Открыть папку результатов».
  - Исходные файлы никогда не перезаписываются. Пакет не запустится, если результат совпадает с исходным файлом
    или две пары пишут в один файл.

## Что нового в версии 1.1
- **Распознавание номера квартиры** (экспериментальное): номер ищется в зелёной «зоне номера», которую
  вы рисуете один раз. Распознанные номера сразу подставляются в таблицу. Неуверенные помечаются оранжевым или жёлтым.
  **Рукописные цифры читаются неточно (примерно 4 из 10 правильно), поэтому всегда проверяйте номера глазами.**
- **Цвет чернил подписи**: синяя / чёрная / любая. Есть ползунок чувствительности и живой образец вырезанной подписи.
- **Большие файлы открываются быстро**: миниатюры рисуются в фоне, только для видимых строк.
- **Отмена**: Ctrl+Z, повтор — Ctrl+Y. Если есть несохранённые изменения, при закрытии программа предупредит.
- **Повёрнутые страницы** (/Rotate): подпись и картинка встают так, как видно на экране.
- **Масштаб**: Ctrl+колесо мыши или кнопки «− + ⤢» под страницей.
- **Журнал ошибок**: меню «Справка» → «Открыть папку с логами» (`%APPDATA%\PdfTool\log.txt`).
  При сбое программа показывает понятное сообщение, а ваши файлы не меняются.
- Программа запоминает последние рамки, зоны и папки. Версия показывается в заголовке окна.

## Экраны

### Подписи
Переносит подпись и расшифровку из актов в расписки.
1. Нажмите **«Открыть акты…»** и выберите PDF с актами, затем **«Открыть расписки…»**.
2. В таблице слева для каждой расписки выберите, из какой страницы акта брать подпись.
   Сначала программа ставит страницы по порядку, это нужно проверить.
   Если подпись ставить не нужно, выберите **«— не ставить (оставить пустой) —»**.
3. **Красная рамка** на акте — откуда берётся подпись. **Синяя рамка** на расписке — куда она встанет.
   - Рамку можно двигать мышью.
   - Размер меняется синим квадратиком в правом нижнем углу.
   - Новую рамку можно нарисовать мышью на пустом месте.
   - Рамка действует сразу на все страницы.
   - Если на одной странице подпись в другом месте, поставьте галочку **«только для этой страницы»** и подвиньте рамку.
4. Внизу выбирается **цвет чернил** (синяя / чёрная / любая) и **чувствительность**. Справа сразу виден образец
   вырезанной подписи. Режим «чёрная» убирает линии бланка, но печатный текст внутри рамки может попасть
   в подпись, поэтому делайте рамку только вокруг подписи.
5. **Автосопоставление по номеру квартиры** (необязательно):
   - Внизу включите «Рисовать мышью: зелёную зону номера квартиры».
   - Нарисуйте зону вокруг номера на акте и на расписке.
   - Нажмите **«Распознать номера и сопоставить»**.
   - Жёлтые строки нужно обязательно проверить, остальные — тоже проверьте по миниатюрам.
   - Если в одном файле бланки разного вида и номер на них в разных местах, автосопоставление почти не работает.
6. **«Предпросмотр»** показывает все расписки с подписями, файл при этом не сохраняется.
7. **«Сохранить новый PDF…»** сохраняет результат.

Как работает программа:
- Из рамки берутся только синие чернила. Фон, линии бланка и печатный текст отбрасываются.
- Всем подписям даётся один цвет ручки.
- Подпись прижимается к левому краю синей рамки.

### Пакет
См. «Что нового в версии 1.2».

### Сортировка
1. **«Открыть PDF…»**. Если в PDF есть текстовый слой, программа сама попробует найти «кв. №».
2. Для сканов: справа нарисуйте зелёную **зону номера** и нажмите **«Распознать номера»**.
   - Заполняются только пустые ячейки.
   - Если в файле два вида бланков, нарисуйте ещё «зону 2».
   - Оранжевые строки означают «распознано неуверенно». Проверьте все номера.
   - Исправить номер можно двойным щелчком по ячейке.
3. Повторяющиеся номера подсвечиваются **красным**, пустые — жёлтым.
4. **«Упорядочить таблицу»** показывает, как страницы встанут после сортировки.
5. **«Сохранить отсортированный PDF…»** сохраняет PDF, **«Сохранить список (CSV)…»** — таблицу для Excel.

### Картинка
1. Откройте PDF и выберите картинку (PNG/JPG), например печать или подпись.
2. Галочка **«Убрать белый фон»** делает белое прозрачным.
3. Перетащите картинку мышью. Размер меняется квадратиком в углу, пропорции сохраняются.
4. Выберите, куда ставить: эта страница, все страницы или список, например `1-3, 5`.
   Затем нажмите **«Сохранить новый PDF…»**.

### Страницы
- **Объединить:** добавьте файлы, расставьте их перетаскиванием и нажмите «Объединить и сохранить».
- **Повернуть или удалить:** откройте PDF, выделите страницы (Ctrl — несколько), нажмите кнопку.
  Порядок страниц меняется перетаскиванием. Затем «Сохранить как новый PDF…».
- **Разделить:** впишите диапазоны (`1-3, 4-6, 7`), каждый станет отдельным файлом.
  Или нажмите «Каждая страница отдельно».

## Для разработчика

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows  (Linux: source .venv/bin/activate)
pip install -r requirements-dev.txt
python run.py                   # запуск
pytest -q tests                 # тесты (реальные PDF ищутся в $PDFTOOL_DATA, иначе пропускаются)
pyinstaller --noconfirm pdftool.spec   # сборка dist/PdfTool.exe
```

Скриншоты экранов без монитора: `QT_QPA_PLATFORM=offscreen python tools/screens.py`.
Размер окна задаётся переменной `SCREEN_SIZE=1920x1080`, приставка имён — `SCREEN_PREFIX`.

Интерфейс:
- `app/ui/style.py` — тема (QSS), шрифт и иконки.
- `app/ui/chrome.py` — шаги, «Дополнительно», зоны перетаскивания, уведомления.
- `app/ui/tour.py` — пошаговые подсказки. Шаги описаны в методе `tour_steps()` каждого экрана.
- `app/ui/helppage.py` — «Справка».

Структура:
- `app/core/` — логика без интерфейса. Это `signatures.py`, `sorting.py`, `pages.py`, `imageinsert.py`,
  `ink.py` (выделение чернил) и `pdfutil.py`.
- `app/ui/` — экраны на PySide6.
- `.github/workflows/build.yml` собирает `PdfTool.exe` на `windows-latest` при push в `main` и при тегах `v*`.
  Для тегов дополнительно создаётся релиз.

Распознавание цифр устроено так:
- `app/core/digits.py` — маленькая свёрточная сеть (2 свёртки + 2 полносвязных слоя), 0,6 МБ весов в
  `app/core/models/digits_cnn.npz`. Сеть считается на numpy, без onnxruntime и torch.
- Обучена на MNIST с аугментацией (перечёркнутые семёрки, единицы с «носиком», разная толщина)
  и на ~190 цифрах из наших сканов.
- Цифры вырезаются по синим чернилам (связные компоненты). Печатный текст бланка отбрасывается.
- Честная точность на файле, который не участвовал в обучении (61 расписка): верно прочитан весь номер
  примерно в 38% страниц. Среди помеченных как «уверенные» верных около половины.

Шаблоны и автоопределение бланка (`app/core/templates.py`):
- Отпечаток — профиль строк печатного текста (тёмные неокрашенные пиксели) при 75 dpi, 600 значений.
- Для каждой страницы и шаблона ищется вертикальный сдвиг окна профиля вокруг зоны номера (±15% высоты).
  Побеждает шаблон с наибольшей корреляцией (порог 0,45), зоны сдвигаются на найденный сдвиг.
- Проверка на job2 (8 актов двух видов): все 8 страниц отнесены к правильному виду бланка.
- **Точность чтения номеров от шаблонов почти не выросла** — ошибается само распознавание рукописных цифр:
  - job2 с шаблонами: акты 1 из 8, расписки 0 из 7, автосопоставление 0 из 6;
  - job3 (61 расписка, модель без job3): 23 из 61 с шаблонами и 23 из 61 без них.
- Пакет: `app/core/batch.py` (`run_batch`, `check_items`).

Рамки хранятся в долях страницы (0–1), поэтому не зависят от DPI и размера скана.
